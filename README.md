# Android Super TV Launcher

Android TV home launcher focused on simple remote control navigation, a refined custom-drawn interface, app slots, app browsing, wallpaper and screensaver controls, file management, APK installation, and optional weather integration.

## Highlights

- Android 4.0+ baseline (`minSdkVersion 14` in the original build configuration)
- Five or ten configurable home app slots
- Full app grid with TV-friendly D-pad navigation
- Custom-drawn home, settings, wallpaper, file manager, and screensaver surfaces
- Built-in wallpaper selection and landscape photo screensaver
- APK installation through Android's package installer flow when direct installation is unavailable
- MET Norway Locationforecast weather provider with manual global location input
- Chinese and English UI resources

## Source layout

The public source snapshot contains only `app/src/main` and artwork documentation. Build scripts, generated output, local caches, signing material, and device-specific files are intentionally excluded.
