# Android Super TV Launcher（超级桌面）

面向 Android TV 的家庭桌面应用，提供遥控器操作友好的自绘界面、应用槽位、应用列表、壁纸与屏保、文件管理、APK 安装和天气接口。

## 功能

- 面向 Android 4.0 及以上版本
- 首页支持 5 个或 10 个自选应用槽位
- 4×5 应用列表和电视遥控器方向键导航
- 自绘首页、设置、壁纸、文件管理器和屏保界面
- 内置自然风景壁纸与照片轮播屏保
- 无法直接安装时调用 Android 系统安装确认流程
- 使用 MET Norway Locationforecast，支持手动输入全球位置
- 中文和英文界面资源

## 目录说明

本公开源码快照只包含 `app/src/main` 和 artwork 说明。Gradle 工程文件、构建产物、本机缓存、签名文件和设备专用文件均未包含。
